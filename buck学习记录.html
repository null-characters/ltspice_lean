1. Buck 电路基础

拓扑与原理

Vin(12V) ──┬── M1(NMOS) ── L1 ──┬── C1 ──┬── Vout
           │                    │        │
           └──── D1 ────────────┘        R1
                                        GND
  • M1 导通：Vin → M1 → L1 → 负载，电感储能
  • M1 关断：L1 通过 D1 续流 → 负载
  • 理想公式：Vout = Vin × D，50% 占空比 → 6V

4. 核心问题：Vout ≠ Vin×D（实测 6.276V，理论 6V）

三大偏差来源

来源 方向 原因 判断依据
DCM 断续模式 偏高 纹波(3A) >> 负载电流(0.6A)，电流降到0 IL_min ≈ 0
高边 NMOS Vgs 不足 偏低 Vgs=Vgate-Vsw 被压缩到 2.58V（阈值2V） Vsw_max=10V≠12V
二极管压降 偏低 Vd≈0.7V，损失 Vd×(1-D)=0.35V Vsw_min=-0.73V

DCM 伏秒平衡：为什么 Vout 反而更高？

电感稳态条件： 一个周期内"充电伏秒 = 放电伏秒"。

CCM（续流占满整个关断期，δ = 1-D）：

(Vin-Vout)×D = Vout×(1-D)
⇒ Vout = Vin×D = 6V

DCM（续流只占 δ，δ < 1-D，存在空闲期）：

(Vin-Vout)×D = Vout×δ
⇒ Vout = Vin×D/(D+δ) > Vin×D

推导：

(Vin-Vout)×D < Vout×(1-D)
⇒ Vin×D - Vout×D < Vout - Vout×D
⇒ Vin×D < Vout
⇒ Vout > Vin×D

直觉理解（水泵/蓄水池比喻）：

  • 导通期储能固定：只由 Vin、Vout、D 决定
  • DCM 里电感提前放空，续流时间 δ 缩短
  • 稳态要求"存多少 = 放多少"，放水时间变短 → 必须抬高 Vout 才能平衡

实测数据验证（DCM：Vout=7.83V）：

δ = (Vin-Vout)×D / Vout = (12-7.83)×0.5 / 7.83 = 0.266
  • 续流只占 26.6%（关断期 50% 里一半多时间是空的）
  • 空闲期 = 50% - 26.6% = 23.4%，全靠 C1 放电维持负载

一句话：DCM 输出更高不是"电感给了更多"，而是"电感提前下班"（空闲期）稀释了能量传递，伏秒平衡迫使 Vout 抬高补偿。

精确公式

Vout = Vin×D - Vd×(1-D) - I×Ron

5. 自举电路（解决高边 NMOS 驱动不足）

原理

自举电容 Cb 在 M1 关断时（sw≈0V）通过 Db 充电至 ~12V； M1 导通时 sw 上升，Cb 下端被抬高，boot = sw+12V，Vgs 恒定。

网表实现

Vcc vcc 0 12
Db vcc boot D          ; 自举二极管
Cb boot sw 100n        ; 自举电容（下端接 sw）
Rboot boot 0 1meg      ; boot 直流路径（防 .op 悬空）
* 驱动芯片模型：Vgs = 11.5V (PWM高) / 0V (PWM低)
B1 drv 0 V=V(sw)+if(V(pwm)>6, 11.5, 0)
Rg drv gate 10         ; 驱动输出阻抗
Cg gate sw 1n          ; 栅极电容

验证结果（对比）

测量项 无自举 有自举 结论
Vgs_max 2.58V 11.5V 恒定 ✓ 驱动不足解决
Vboot_max - 26.6V ✓ 举升正常
Vsw_max 10.0V 14.4V MOS 充分导通
Vout_avg 6.28V 7.83V 仍偏高（DCM 遗留）

实现经验（仿真收敛坑）

  1. 自举电容使 boot 节点悬空 → 加 Rboot 直流路径
  2. 理想开关/受控源直接驱动 gate 导致收敛失败（Singular matrix / Heightened Def Con）
    • 改用 B 源 + 输出电阻 Rg + 栅极电容 Cg
    • 驱动器表达式只依赖 V(sw)，不依赖 V(boot)，打破反馈环

6. DCM vs CCM 对比实验

背景：boot 电压异常现象

现象： 观察 boot 节点波形，PWM 低电平期间 boot 没有回到 12V，而是停在 ~20V。

原因： V(boot) = V(sw) + V(Cb)，DCM 模式下 M1 关断期分两段：

阶段 sw 电压 boot 电压
① 续流期（D1 导通） ≈ -0.7V 被 Db 拉回 ~11V
② 空闲期（电流=0） ≈ Vout Vout + Vcb ≈ 20V ✓

电感电流降到 0 后 D1 截止、sw 不再被钳位到地，而是等于 Vout； Cb 已充满且无放电通路 → boot = Vout + Vcb ≈ 20V。这是 DCM 的正常特征。

实验：改电感进入 CCM

仅将 L1 10u → 100u（文件 buck_ccm.cir，其余与 buck.cir 完全一致）。

结果对比（自举驱动电路）

测量项 DCM (L=10µ) CCM (L=100µ) 说明
IL_min ≈0 0.40A > 0 ✓ 确认 CCM
Vout_avg 7.83V 5.72V CCM 更接近理论6V
Vsw_max 14.4V 12.0V MOS 充分导通
Vsw_min -0.74V -0.71V 续流压降
Vgs_max 11.5V 11.5V 自举正常
Vboot_max 26.6V 24.3V 举升正常
Vboot_min 11.5V 11.5V 见下

boot 低电平的 DCM/CCM 对比

模式 M1 关断期间 sw 状态 boot 低电平
DCM 续流期 -0.7V → 空闲期 =Vout(7.8V) 大部分时间 ≈ 20V
CCM 续流期全程 -0.7V（电流不断） 全程被 Db 拉回 ≈ 11.5V

结论： boot 低电平是否回到 12V 附近，可用于快速判断工作模式。

CCM 收敛坑：代数环 Singular matrix

现象： 只改 L=100µ 后仿真报 Singular matrix: check node gate。

原因： 大电感使开关切换更硬（电流不为 0），驱动表达式 B1: drv = V(sw)+11.5 与 M1: sw = f(Vgs) 形成代数环， 环路增益过高 → 矩阵奇异。

解决： 加 Cgnd gate 0 1n（gate 对地电容），打断瞬时代数环。 1nF 相对主电路（µH/µF 级）影响可忽略，不改变电路行为。

经验： 对比实验应保持两文件仅一处功能差异（此例只有 L1）， 其余注释/结构完全一致，diff 一目了然。

7. 波形与电流解读

7.1 v(drv) 为什么是 -0.68V ~ 23.3V？

驱动表达式：V(drv) = V(sw) + if(V(pwm)>6, 11.5, 0)

PWM 状态 sw 电压 V(drv) 说明
高电平（M1导通） ≈12V 23.3V 12 + 11.5（自举叠加）
低电平（M1关断,D1续流） ≈-0.7V -0.68V D1 钳位

负值来源： 续流二极管正向压降。D1 阳极接地、阴极接 sw， 导通时 0 - V(sw) = 0.7V → sw 被钳位到 -0.7V，drv 跟随。

关键： 驱动看 Vgs = V(gate)-V(sw) = 11.5V/0V 恒定， drv 绝对电压随 sw 浮动是设计使然，非故障。

7.2 各节点电流含义

主功率路径：

电流 位置 含义
i(L1) 电感 核心：负载电流+纹波，锯齿波；判断 DCM/CCM
i(R1) 负载 输出电流 = Vout/R1，近似直流
i(D1) 续流二极管 M1 关断期间流过，补上 id 归零后的缺口
i(C1) 输出电容 纹波电流 = i(L1)-i(R1)，正负交替，平均值≈0

自举/驱动路径（毫安级小电流）：

电流 位置 含义
i(Cb) 自举电容 导通瞬间的电荷转移脉冲
i(Db) 自举二极管 关断期间给 Cb 充电
i(Cg) 栅极电容 开关沿的充放电尖峰
i(B1) 驱动源 驱动级总输出 ≈ i(Cg)

关键关系：

i(L1) = i(R1) + i(C1)        （节点 out，KCL）
i(M1) + i(D1) = i(L1)        （节点 sw，两管互补拼接成电感电流）
i(C1) 平均值 ≈ 0             （电容不承担直流负载）

7.3 DCM 电流三阶段（id 从0爬升 → 突变 → 同降）

阶段 id (M1) i(L1) i(C1)
① M1导通 从0爬升 从0线性升 超过 i(R1) 后为正（充电）
② 关断瞬间 突变为0 连续不变（被D1接管） 继续下降
③ 关断期间 0 线性降到0 从正转负（放电）
  • id 从 0 爬升 = DCM 特征（CCM 下 id 从 IL_min>0 开始）
  • id 突变归零 = 电流换路，i(L1) 不能突变，由 D1 无缝接管
  • id/ic 一起下降 = 电感释放能量，i(L1)<i(R1) 后 C1 放电补负载

7.4 i(C1) 为什么变负？

i(C1) = i(L1) - i(R1)
  • i(R1) 恒定 ≈ 0.78A
  • 后半周期 i(L1) < i(R1) → i(C1) < 0 = 电容放电

正负含义：

正 i(C1)：电感富余 → 电容充电（Vout 上升，纹波波峰）
负 i(C1)：电感不足 → 电容放电补负载（Vout 下降，纹波波谷）

验证： AVG[i(C1)] ≈ 0（充电量=放电量，能量守恒）。

8. 滞环闭环控制（buck_hysteresis.cir）

目标

对 Vout 闭环稳压，不使用 PI，而是滞环调占空比：

  • 保持固定频率 PWM（50kHz），不是开关/关断
  • Vout < Vref-0.1 → 增大占空比；Vout > Vref+0.1 → 减小占空比
  • 窗口内 → 保持（滞环死区 = 记忆，电容提供）
  • Vref 可编程：10ms 处 6V→8V 突变，验证闭环跟踪能力

控制架构

锯齿波载波(50kHz) ──┐
                     ├── if(tri < dctrl) → PWM ── 驱动M1
Vout ── 滞环比较器 ── Gint积分 ── dctrl(占空比指令) ──┘
   │
   └── 阈值 = Vref±0.1（Vref 由 B 源生成，可突变）

网表核心

*载波：锯齿波 0~12V，50kHz（PULSE 参数需 Trise+Ton+Tfall=周期）
Vtri tri 0 PULSE(0 12 0 19.6u 0.2u 0.2u 20u)
*Vref：6V，10ms 处 0.1ms 斜坡升至 8V
Bref ref 0 V=6+2*limit((time-10m)/0.1m,0,1)
*滞环积分器（sigmoid 平滑死区，阈值 = Vref±0.1）
Gint 0 dctrl VALUE={0.2m*(1/(1+exp((V(out)-V(ref)+0.1)*20)) - 1/(1+exp((V(ref)+0.1-V(out))*20)))}
Cdctrl dctrl 0 1u ic=6
*PWM 比较：载波 < 占空比指令 → 导通
Bpwm pwm 0 V=if(V(tri)<V(dctrl), 12, 0)

仿真结果（Vref 突变实验）

时段 Vref Vout dctrl（占空比）
0~10ms 6V 5.95V 6.32V（53%）
10ms 突变 6→8V 爬升调节 6.3→8.2V
18~25ms 8V 7.94V ≈ 8V ✓ 8.23V（69%）
  • Vout 稳态波动 ±0.05V，在 ±0.1V 滞环窗口内 ✓
  • 占空比自动调节可见：53% → 69%（补偿二极管压降 + 输出升高）
  • IL = 0.80A = 8V/10Ω ✓
  • 闭环优势：Vref 突变后自动跟踪，无需手动改占空比

实现经验（7 个收敛坑）

问题 现象 解决
G源方向 dctrl 变负值 Gint 0 dctrl（电流流入节点才充电）
.op 奇异 dctrl=100kV（1mA×100MΩ） .tran uic 跳过 .op + 电容 ic= 初值
锯齿波溢出 Trise+Ton+Tfall > 周期 参数和 = 周期（19.6u+0.2u+0.2u=20u）
缺 Cgnd gate 奇异（L=100µ 代数环） 补 Cgnd gate 0 1n
100kHz 长仿真卡死 .tran≥14ms 必卡（.raw 停 22MB，无报错） 载波降 50kHz（开关事件减半）
Vref 突变触发崩溃 突变后 Vout 大幅振荡 B 源 0.1ms 平滑斜坡（limit()）
积分增益过高振荡 Vout ±0.5V 反复穿越窗口 0.5m→0.2m，波动降到 ±0.05V

关键教训：长仿真卡死排查

  1. 先做极简电路隔离：去掉控制器只剩"载波+PWM+功率级"，若仍卡 → 问题在基础电路
  2. 二分定位卡点：8/12/14/18/22/25ms 逐步逼近，确认卡死时间范围
  3. 区分三类问题：
    • 基础电路卡死 → 开关频率（100kHz→50kHz）
    • 控制器触发 → 突变平滑化（B 源斜坡）
    • 参数不匹配 → 积分增益（0.5m→0.2m）
  4. Vout 波动超窗口是预警：波动 ±0.5V >> 窗口 ±0.1V 说明环路振荡，先调参数再谈仿真

9. PI 控制器（buck_pi.cir）

目标

把滞环控制升级为 PI 控制（学习计划实验 1.1），与滞环版做最小化对比。 核心：duty = Kp*e + Ki*∫e dt，其中 e = Vref - Vout。

最小化差异（vs 滞环版）

部分 滞环版 PI 版
误差 Gint（sigmoid 死区饱和） Berr（显式误差 e=Vref-Vout）
积分项 Cdctrl 电容 Gi（tanh 限幅）+ Ci 电容
比例项 无（死区代替） Bp（tanh 限幅，串联）
钳位 Rdc + Dclamp 二极管 tanh 软限幅（无需额外元件）

其余（载波/Vref/自举/驱动/功率级/测量）100% 一致。

网表核心（限幅 PI）

*误差
Berr err 0 V=V(ref)-V(out)
*积分项：tanh 限幅电流源（±0.2mA）+ 电容（无静差）
Gi 0 int VALUE={0.2m*tanh(V(err)/0.05)}
Ci int 0 1u ic=6
*比例项：tanh 软限幅电压源（±5V）串联
Bp dctrl int V=5*tanh(V(err)/1)
*dctrl = 积分 + 比例

仿真结果（vs 滞环版）

指标 滞环版 PI 版
Vout_avg 7.94V 7.98V
Duty 爬升 52.7%→68.6% 52.9%→69.0%
Vout 波动 ±0.05V ±0.05V
IL 0.798A 0.798A

两者稳态结果几乎一致（都能稳压 8V）——区别在动态响应（PI 有即时比例反应，滞环靠积分慢推）。

关键设计：为什么 PI 必须"限幅"

  • 无界线性误差电流会数值崩溃：启动时 e=6V → 线性电流 12mA → dctrl 剧烈冲高 + 二极管高频钳位
  • 限幅 PI（tanh 软限幅）：电流有界（±0.2mA），dctrl 变化率受控 → 与滞环版同样收敛
  • tanh 软限幅 vs 硬 limit：软限幅连续可导，避免 Newton-Raphson 啃尖角

经验教训：LTspice 批处理"卡死"误判

现象：LTspice.exe -b -Run xx.cir 前台命令 120~180s 超时，.raw 停在 ~26MB，log 只有头部 → 误判为仿真卡死，反复改电路。

真相：仿真每次 3~5 秒就完成了（.raw 已写完），但 LTspice 批处理进程跑完后有时不退出/不写 .log，导致 shell 等待超时。

教训：

  1. 先看 log 全文再判断——"Total elapsed time" 出现即仿真完成
  2. .raw 停止增长 ≠ 卡死，可能是进程退出环节问题
  3. 验证用 GUI 或后台任务 + 轮询 log，避免被前台超时误导
  4. 多轮"修复"实际是徒劳，电路从头到尾都是对的

深入：模拟 vs 数字在"限幅"上的处理区别

背景：PI 在 SPICE 里需要输入限幅（tanh），而软件里通常只做输出限幅 + 抗积分饱和。为什么不一样？

根本差异：无界值的"危害"不同

软件（数字） SPICE（模拟）
无界中间值（Kp*e=30V） 无害：寄存器能存，下一行 clamp 有害：30V 是真实电压，驱动电路极端
限幅实现 if(u>Umax) u=Umax（一行代码） 二极管钳位（物理元件）或 tanh 信号软化
收敛要求 无（不迭代求导） 有（Newton-Raphson 需连续可导）

软件为什么能"先算后限幅"：无界计算只是寄存器里的数，不产生物理后果 → 标准做法是 u=Kp*e; clamp(u) + 积分钳位（抗饱和）。

仿真为什么用输入限幅（tanh）：无界 = 真实电压/电流 → 驱动电路进入极端状态 + 硬钳位高频动作 → 数值崩溃。tanh 在信号源头软限幅（连续可导）→ 最平滑收敛。

输出限幅也可行（贴近软件习惯）：比例项不限幅 + 经电阻到非理想节点 + 二极管钳位——但二极管导通/关断有电流突变，数值比 tanh 略硬。

附赠：tanh 输入限幅隐含抗积分饱和 软件要显式冻结积分器防 windup；tanh 限幅误差 → 积分电流恒 ≤±0.2mA → 积分器根本不会 windup → 天然抗饱和 ✓

tanh 能否直接用到 MCU？——能但没必要：

  • 带 FPU 的 MCU（Cortex-M4F）算 tanhf 约百周期，50kHz 环完全够
  • 但软件没有收敛约束，硬限幅 + 积分钳位一行代码更简单高效
  • 想要软饱和效果可用：分段线性近似 / 查表 / 硬限幅（够用）

一句话：限幅方式由"载体的物理约束"决定——数字算完再 clamp 无害，模拟必须让信号源头有界；tanh 是仿真专属需求，不是 MCU 的必需品。

嵌入式映射：Kp 决定"即时反应"，Ki 决定"消除静差"；固件 PID 整定时，Kp 增大加快响应但超调风险上升，输出限幅/抗饱和能压制超调。

11. 实验 1.2：环路稳定性分析

方法：开关电路无法直接 .ac，用平均化小信号模型（受控源替代开关）+ 解析传递函数。

功率级（CCM 平均模型）：

Gvd(s) = Vout/dctrl = 1 / (s²LC + sL/R + 1)

验证：10Hz 处 |Gvd|≈0dB，与 LTspice .ac 实测一致 ✓

环路增益：T(s) = (Kp + Ki/s) * Gvd(s)（H=1 直接反馈）

结果（Kp=5, Ki=1000, L=100µH）：

  • 增益穿越频率 fc = 3897 Hz
  • 相位裕度 PM = 2.3°（临界不稳定！）

Kp 扫描（L=100µH）：

Kp fc (Hz) PM 判据
0.5 187 119.8° 稳定 ✓
1.0 2247 4.0° 临界
5.0 3897 2.3° 临界
20 7292 1.3° 临界

→ Kp↑ → fc↑、PM↓ ✓

L 扫描（Kp=5）：

L (µH) fc (Hz) PM
50 5512 1.7°
100 3897 2.3°
400 1945 4.7°

→ L↑ → fc↓、PM↑ ✓

验证标准对照：PM>45° 稳定（仅 Kp=0.5 满足）✅；Kp↑ 裕度↓ ✅；L↑ 穿越↓ ✅

关键发现（重要）：

  • LC 谐振 f0 = 1/(2π√(LC)) ≈ 1592Hz，而 fc=3897Hz 穿越在谐振点之后
  • LC 双极点贡献 180° 滞后 + 积分项 90° → 穿越处相位逼近 -180°
  • 正确设计应让 fc 远低于 f0（工程经验：fc < f0/5，如 fc≈300Hz），否则相位裕度不足
  • 这也解释了实验 1.1 中 Kp=5 大超调（8.7V）——低相位裕度的时域表现

嵌入式映射：数字电源 PID 参数必须有相位裕度依据——穿越频率定带宽、相位裕度定稳定储备；不能盲调参数，这就是固件稳定性设计的理论根基。

手推延伸：从 fc/PM 反推 Kp/Ki（完整过程）

设计目标：fc = 300Hz（约 f0/5），PM ≥ 45°

已知：L=100µH, C=100µF, R=10Ω，f0=1/(2π√LC)=1592Hz

步骤 1：算 Gvd 在 fc 处的幅值和相位

ωc = 2π·300 = 1885 rad/s
Gvd = 1/(1-ω²LC + jωL/R)
ω²LC = 1885²·1e-8 = 0.0355
ωL/R = 1885·1e-4/10 = 0.0189
|Gvd| = 1/√(0.9645²+0.0189²) ≈ 1.037
∠Gvd = -atan(0.0189/0.9645) ≈ -1.1°

步骤 2：定 PI 零点（保证 fc 处相位贡献小）

令 ωz = Ki/Kp = ωc/10 = 188.5 rad/s
→ 在 fc 处：Ki/(ωc·Kp) = 0.1，∠Gc = -atan(0.1) ≈ -5.7°

步骤 3：增益条件 |T(fc)| = 1 定 Kp

|Gc| = Kp·√(1+0.1²) = 1.005·Kp
|T| = 1.005·Kp·1.037 = 1 → Kp = 0.96
Ki = ωz·Kp = 188.5·0.96 = 181

步骤 4：验证相位裕度

∠T = ∠Gc + ∠Gvd = -5.7° + (-1.1°) = -6.8°
PM = 180° - 6.8° = 173°  ✓ 远大于 45°

步骤 5：解读——为什么 PM 这么大？

fc=300Hz << f0=1592Hz → Gvd 几乎无相位滞后（-1°）
→ 总相位滞后仅 6.8° → PM 巨大

代价：fc 低 = 带宽低 = 响应慢。这是"稳定与速度"的权衡。

步骤 6：迭代提 fc（若需更快响应）

提高 fc 直到 PM 降到 45-60°（如 fc=800Hz 重新算 Gvd）
fc 越接近 f0，Gvd 相位骤降 → PM 快速变小 → 找到响应与稳定的平衡点

设计流程总结（可复用）：

① 选 fc（带宽目标，经验 fc < f0/5 起步）
② 算 Gvd(fc) 幅值相位
③ 定 PI 零点 ωz = fc/10
④ 由 |T(fc)|=1 解 Kp，再由 Ki=ωz·Kp 解 Ki
⑤ 算 PM 验证；PM 太大→提 fc 迭代，PM<45°→降 fc 或加补偿
⑥ 时域 .tran 验证

嵌入式映射：这套手推就是固件 PID 整定的"解析法"——Kp/Ki 由 fc/PM 目标反推，而不是盲目试参。仿真或实机验证只是最后确认。

12. 环路理论：概念基础

12.1 小信号线性化 & 平均化模型（软件视角）

给软件背景读者：为什么开关电路不能直接 .ac，平均化到底是什么。

① 什么是线性系统

① 叠加性 f(a+b)=f(a)+f(b)
② 齐次性 f(k·x)=k·f(x)
  • 只有线性系统才能用拉普拉斯/傅里叶变换做频域分析
  • 开关电路（MOS 通断、二极管换流）是强非线性 → 不能直接频域分析

② 什么是 .ac 小信号线性化

1. 求直流工作点（电容开路、电感短路，电路"静止"）
2. 在该点用斜率（导数）代替曲线（泰勒一阶：f(x0+Δx)≈f(x0)+f'(x0)Δx）
3. 注入 1V 正弦，扫频，输出增益+相位
  • 失效原因：开关电路没有固定工作点（MOS 每 20µs 开关一次，永远在动），强行线性化得到假结果
  • 软件类比：对非周期信号做 FFT，结果看似有条纹实际是错的

③ 平均化模型（核心）

  • 思路：只关心开关周期之上的慢变行为（环路调节），取一个周期的时间平均
  • 数学本质 = 以开关频率为界的低通滤波（丢弃 50kHz 斩波高频，保留环路低频趋势）
  • 软件类比：滑动平均/低通滤波去噪，只剩信号的趋势
真实开关：vsw = Vin（导通）/ 0（续流）→ 非线性
平均化后：vsw = d × Vin（受控源）     → 线性！

④ 平均化后电路变线性

[开关网络] ── L ──┬── C ── R     ← 原：非线性
[受控源]  ── L ──┬── C ── R     ← 后：纯 L-C-R 线性网络

→ 受控源线性 + L/C/R 线性 → 可以 .ac 了（buck_ac.cir 的 Esw 就是干这个）

⑤ 完整思维链

Buck（非线性）→ 平均化（低通）→ 线性模型 → Gvd(s) 解析
→ T(s)=Gc·Gvd（开环增益）→ 波特图 → 相位裕度 → 稳定性

一句话：小信号线性化 = 在静止点用斜率近似；平均化 = 把开关通断"低通滤波"掉只剩趋势，从而把非线性电路变成可频域分析的线性电路；.ac 失效 = 开关电路没有静止点。

12.2 .ac 起什么作用？环路增益怎么测？

.ac 的机制（三步）：

1. 找直流工作点（电容开路、电感短路）
2. 线性化（工作点处用斜率代替曲线）
3. 复频域求解：对每个频率解代数方程 → 增益+相位

软件类比：给系统传函采样频率响应（类似 freqz 画滤波器幅相特性）。

.ac 的三大作用：

  1. 频率特性：带宽（-3dB 点）、谐振峰、滚降斜率
  2. 稳定性判断（核心）：环路增益 T(s) 的 fc 和 PM
  3. 验证数学推导：手推 Gvd(s) 用 .ac 对照

关键：注入点必须是"环路断开处"，不是输入端：

注入位置 测到 意义
输入端 Vout/Vin 只是电源对扰动的响应，不含反馈环
环路断开处 环路增益 T(s) 含控制器+功率级+反馈全链，决定稳定性 
       ┌──────── 环路断开，注入 ac ────────┐
       ↓                                  │
[误差] → [Gc 控制器] → [Gvd 功率级] → [Vout] ─┘
         ↑ 返回 = 输入 × T(s)

T(s) 含义：信号绕环路一圈的放大倍数。|T|<1 稳定；|T|≥1 且相位-180° 振荡。

完整理解链（定 Kp/Ki 的流程）：

疑问 Kp/Ki 取多少？
  ↓ 平均化 → 线性系统（Gvd、Gc）
  ↓ 环路断开处注入扫频 → T(s)=Gc·Gvd
  ↓ 读 fc（|T|过0dB）、PM（fc处相位+180°）
  ↓ PM>45° 稳定；PM<0° 振荡
  ↓ 调 Kp/Ki → fc 和 PM 落在设计目标（fc<f0/5，PM>45°）
  ↓ 时域 .tran 验证（无超调/无振荡）
  ↓ 得最优 Kp/Ki

一句话：.ac = 在静止点线性化后注入不同频率正弦，测放大倍数和相位延迟，回答"系统对什么频率响应、什么频率会振荡"。对开关电路先平均化才能用。测稳定性必须断开环路测 T(s)，而不是测输入端传递函数。

12.3 H(s) + G(s) + 环路断开 = 反推控制器参数

标准控制框图（把实验 1.2 符号化）：

        ┌──────── G(s) ──────── H(s) ────────┐
r ──(+)──┤  (控制器 PI)     (功率级 Buck)      ├── y (Vout)
     (-) │                                    │
        └─────────── 反馈(系数=1) ────────────┘
  • H(s) = 被控对象 = Gvd(s) = 1/(s²LC+sL/R+1)（功率级，已知/可测）
  • G(s) = 控制器 = Kp + Ki/s（待定参数）
  • 环路增益 T(s) = G(s)·H(s)（反馈系数 1）

待求解的 G(s) 参数（Kp/Ki）→ 通过测 T(s) 反推：

1. 环路断开处注入小信号（Middlebrook 法）
2. 测绕一圈的总增益 = T(s) = G·H
3. 从 T(s) 读 fc（|T|=0dB）和 PM（fc 处相位+180°）
4. 因 H 已知，T 的形状 → 反推 G 的参数

断开点选哪都行：误差点或输出反馈点等价（都测 G·H）。

术语修正：

  • "开环传递函数"严格指 T(s) = G·H（环路断开时的总增益）
  • H(s) 单独叫"被控对象传递函数"，G(s) 叫"控制器传递函数"

一句话：H(s) 是功率级、G(s) 是待定控制器，断开环路注入小信号测得 T(s)=G·H，从 T(s) 的 fc 和 PM 反推 Kp/Ki——这就是环路设计的全部逻辑（Middlebrook 测量法原理）。

12.4 为什么频域分析必要？L/C 的本质（4 问 4 答）

① 纯阻性电路需要频域分析吗？——不需要

  • 纯阻性：阻抗不随频率变，Vout = Vin·R2/(R1+R2) 对所有频率恒成立，一个代数方程就够
  • 含 L/C：阻抗随频率变（L 阻抗=jωL，C 阻抗=1/(jωC)）→ 必须频域
  • 软件类比：纯阻性=无状态函数 y=2x；含 L/C=有状态系统（IIR），必须用 H(s)/H(z) 描述

② 为什么 L/C 引入频率依赖？——微分/积分 = 记忆

电感：v = L·di/dt   （微分）
电容：i = C·dv/dt   （微分）

微分/积分 → 系统有状态、输出依赖历史 → 用频率描述"记忆长度"（不同频率经历的记忆不同）

③ 纯感性 vs 纯容性分析区别？——相位相反

纯 L 纯 C
阻抗 jωL 1/(jωC)
相位 +90° -90°
低频 短路 断路
高频 断路 短路
  • 纯 L 配合 R 做高通；纯 C 配合 R 做低通
  • L+C 相位相反 → 谐振频率互相抵消 → 谐振峰
  • 相位决定稳定性（PM），故必须看完整波特图（幅值+相位）

④ 为什么 fc 要远低于 f0（谐振）？——LC 相位骤降 -180°

fc << f0：∠Gvd ≈ 0°   → PM 大，稳
fc = f0： ∠Gvd ≈ -90°（且 -40dB/dec 陡降）
fc >> f0：∠Gvd → -180° → 环路相位超 -180° → 振荡
  • LC 双极点共贡献 -180°（每个 -90°），加 PI 积分器 -90° → 总相位必超 -180°
  • 工程经验：fc = f0/5 起步，fc ≥ f0 必不稳
  • 留余量是为了容忍参数漂移（电感饱和、电容老化 ±20%）

⑤ fc 的作用 & 与 Kp/Ki 的关联

  • fc 三作用：控制带宽（响应速度）/ PM 读取点 / 噪声滤波边界
  • Kp 决定 fc：|T(fc)|=1 → Kp ≈ 1/|Gvd(fc)|，Kp↑ → fc↑
  • Ki 决定低频：消除静差，设计 PI 零点 = fc/10（保证 fc 处积分项相位影响 <10°）
  • fc 是设计锚点：先定 fc（带宽需求）→ 解 Kp → 解 Ki → 查 PM 验证

一句话：频域分析之所以必要，是因为 L/C 的"记忆"（微分/积分）让电路行为随频率变化；fc 是带宽设计锚点（Kp 定它），f0 是稳定红线（fc 必须远低于它）。

12.5 为什么"增益=1"（fc）这么重要？与真实工作的联系

① 增益=1 的物理意义（信号绕一圈）

误差 → Gc → Gvd → Vout → 反馈 → 回到误差
      （信号绕一圈被放大 T 倍）
  • |T|>1：信号绕一圈变大 → 环路在起作用（强负反馈）
  • |T|<1：信号绕一圈变小 → 环路管不动这些频率
  • |T|=1（fc）= 分界线：环路"还管得动"的最高频率

② 为什么 fc 处相位决定振荡（自激条件）

若某频率满足：|T|≥1 且 ∠T=-180°（负反馈变正反馈）
→ 信号绕一圈同相且不衰减 → 叠加增强 → 自激振荡

fc 是"增益还够=1"的地方，再高频率增益衰减振荡不起 → 振荡最可能发生在 fc 附近 → 必须查 fc 处相位（PM）

③ fc = 控制带宽：真实扰动也是"频谱"的

真实扰动 频率 相对 fc 环路作用
负载突变（功耗跳变） 低频 < fc 深度抑制（稳压）
输入波动（整流纹波） 50/100Hz << fc 深度抑制
开关纹波（PWM） 50kHz >> fc 环路不管，靠 LC 滤
高频噪声 MHz >> fc 环路不管

④ 定量：灵敏度函数 S(s)=1/(1+T(s))

f << fc：T 大 → S≈1/T → 扰动被抑制 1/T 倍
f = fc： T=1  → S=1/2（-6dB）→ 抑制剩一半
f >> fc：T 小 → S≈1 → 扰动原样通过

fc = S 的转折点 = 控制带宽 = "能跟上/抑制的最快扰动频率"

软件类比：fc = 控制系统带宽/响应速度上限——扰动太快（>fc）控制器反应不过来，像 PID 的采样带宽。

一句话：fc（增益=1 点）= 环路"还管得动"的最高频率 = 控制带宽。低于 fc 的扰动（负载/输入波动）被抑制，高于 fc 的（开关纹波/噪声）靠 LC 滤。自激振荡恰好发生在 fc 这个"增益还够"的点——所以设计必须保证 fc 处相位裕度足够（fc 远低于 f0 正是为此）。

12.6 fc vs f0 的位置关系 = 稳定性的全部秘密

① 现象：实验 1.2 中 fc=3897Hz > f0=1592Hz → PM=2.3°（临界不稳定）

② f0 = LC 谐振频率 = 相位"急转弯"的拐点

f0 = 1/(2π√(LC)) = 1592Hz，三个含义：
1. 物理共振：L/C 阻抗互相抵消，功率级自身增益有峰值
2. 相位拐点：f0 前后 ∠Gvd 从 0° 快速滑向 -180°
3. 功率级"带宽天花板"：能自然通过信号的上限

③ 为什么 fc < f0 才能保证 PM（核心机制）

∠Gvd(f) 变化：
  f << f0：∠Gvd ≈ 0°（L短路C断路，纯电阻）
  f = f0： ∠Gvd ≈ -90°（相位拐点）
  f >> f0：∠Gvd → -180°（双极点渐近）

PM = 180° + ∠Gc(fc) + ∠Gvd(fc)

① fc << f0：∠Gvd≈0° → PM≈90°~180° ✓ 稳
② fc >> f0：∠Gvd≈-180° → PM≈∠Gc≈-90°~0° ✗ 危险

④ 为什么拐弯这么急：LC 是二阶（双极点），相位在 f0 附近一个十倍频内从 -90° 冲到接近 -180°（-40dB/dec 滚降对应 180° 相位滞后）→ fc 稍越过 f0，PM 迅速恶化

⑤ 图示

|T| (dB)
  ↑  ╱‾‾‾‾‾ ← T>0dB：环路管得住（深度抑制）
  │ ╱
0 ├──────┼─── fc ← 边界（管得住/管不住）
  │      ╲
  │       ╲ ← T<0dB：环路管不住（靠 LC）
  └───┴────┴──→ 频率
     f0=1592  fc=3897
     ↑相位拐点 ↑已过拐点 → PM=2.3°危险

⑥ 正确设计：fc 落在 f0 左侧（fc < f0/5）→ ∠Gvd 还没拐弯（≈-1°）→ PM 巨大（fc=300Hz 手推得 PM=173°）→ 极稳，代价是带宽低

一句话：f0 是相位急转弯的拐点，fc 是控制带宽边界；fc > f0 意味着穿越点已落在相位骤降区之后（∠Gvd≈-180°）→ PM≈0 → 临界不稳定；fc 远低于 f0 才能保证穿越时相位还没烂 → PM 充足。这就是 "fc < f0/5" 的依据。

14. 经验总结

  1. Vout = Vin×D 仅在 CCM + 理想器件下严格成立
  2. 判断工作模式看电感电流：IL_min > 0 → CCM；≈0 → DCM（输出偏高）
  3. 高边 NMOS 必须自举驱动（或低边 NMOS / 同步整流）
  4. boot 低电平判断模式：回到 12V 附近 → CCM；停在 ~Vout+Vcb → DCM
  5. 自举仿真要点：boot 节点加直流路径；驱动源加输出阻抗，避免理想源反馈环
  6. 大电感触发代数环奇异：驱动 B 源依赖 sw 时，加 Cgnd 打断反馈环
  7. 对比实验最小差异原则：两文件只留一处功能差异，便于直观对比
  8. drv 绝对值浮动正常：看 Vgs 而非 V(drv)；负值来自二极管钳位 -0.7V
  9. 电流看 KCL：i(L1)=i(R1)+i(C1)；i(M1)+i(D1)=i(L1)；i(C1) 平均≈0
  10. i(C1) 负值 = 电容放电，对应 Vout 纹波波谷，属正常现象
  11. PI 必须限幅：无界线性误差电流数值崩溃，tanh 软限幅保证收敛（与滞环同结构）
  12. LTspice 批处理误判坑：.raw 写完但进程不退出 ≠ 卡死，先看 log 的 Total elapsed time 再判断
  13. µ 用 u；注释用英文；FLAG 节点名与 .meas 一致
